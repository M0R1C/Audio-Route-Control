# Audio Route Control

Нативное Windows-приложение для маршрутизации звука по приложениям.

## Возможности

- список активных аудиосессий Windows;
- выбор устройства вывода для каждого приложения;
- отдельная громкость и mute для каждого источника;
- сохранение правил в `%APPDATA%\AudioRouteControl\settings.json`;
- автоматическое повторное применение правил при следующем запуске приложения;
- быстрый микшер по левому клику на значок в системном трее;
- интерфейс в тёмном стиле Windows 11 с округлыми карточками и быстрыми действиями;
- режимы отображения «Список» и «Сетка»;
- автоматическое обновление без пересоздания интерфейса при каждом тике таймера;
- один self-contained `.exe`, без установки .NET.

## Готовая portable-версия

Готовая версия находится в `release\AudioRouteControl.exe`.

Это self-contained portable-сборка для Windows 10/11 x64: установка .NET и дополнительные DLL не нужны. Достаточно перенести `AudioRouteControl.exe` на другой компьютер и запустить.

Настройки пользователя хранятся отдельно в `%APPDATA%\AudioRouteControl\settings.json`. Чтобы перенести сохранённые громкости, mute и маршруты на другой компьютер, скопируйте этот файл.

## Сборка из исходников

Требуется .NET 8 SDK:

```powershell
dotnet restore -r win-x64
dotnet publish -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

Готовый файл будет в `bin\Release\net8.0-windows\win-x64\publish\AudioRouteControl.exe`.

Приложение рассчитано на Windows 10/11 x64. Для Discord/браузеров важно, чтобы приложение уже воспроизводило звук: именно активные аудиосессии показываются в списке. Если Discord запущен, но ничего не проигрывает, Windows может не создать для него активную сессию — в таком случае он появится после начала воспроизведения.
